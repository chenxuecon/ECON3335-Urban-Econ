# ECON3335 Urban and Regional Economics

Course materials for ECON3335: Urban and Regional Economics, Spring 2027, St. Edward's University.

## Course Website

The student-facing course homepage is [`index.md`](index.md). It links to:

- the syllabus
- weekly lecture slides in HTML and PDF format
- problem sets
- course readings
- extra lecture handouts and examples

## Folder Map

- `syllabus/`: course syllabus PDF
- `slides/`: weekly lecture decks and supporting files
- `problem-sets/`: problem set PDFs
- `resources/`: textbook and reading PDFs
- `index.md`: public course webpage for students
- `_config.yml`: GitHub Pages/Jekyll configuration

## Publishing

This repository is configured for GitHub Pages through the `jekyll-theme-minimal` theme. After updates are pushed to GitHub, students can use the published GitHub Pages URL as the course materials hub.
